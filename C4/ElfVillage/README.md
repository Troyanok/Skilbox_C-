# Деревня эльфов

Программа моделирует расселение эльфов по веткам деревьев. Поддерживает генерацию случайного леса, заселение, поиск эльфа и подсчёт соседей. Используется стиль Allman, комментарии Doxygen (`///`), `#pragma once`.

## Сборка

```bash
mkdir build && cd build
cmake ..
make
./elf_village
