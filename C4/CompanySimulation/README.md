# Симуляция работы компании

Программа моделирует иерархическую компанию с командами и менеджерами. Глава компании выдаёт директивы, менеджеры распределяют задачи. Используется стиль Allman, комментарии Doxygen (`///`), `#pragma once`.

## Сборка

```bash
mkdir build && cd build
cmake ..
make
./company_app
